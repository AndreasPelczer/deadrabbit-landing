PlanktonSprite

Über die App

PlanktonSprite ist ein Pixel-Sprite-Animator für Indie-Gameentwickler. Erstellen Sie Frame-Animationen mit Onion Skin, exportieren Sie als GIF oder Spritesheet und nutzen Sie Engine-Presets für Unity, Godot und SpriteKit — komplett offline, ohne Account.

Häufige Fragen (FAQ)

In welchen Formaten kann ich exportieren?

PlanktonSprite exportiert als animiertes GIF und als Spritesheet (PNG). Zusätzlich stehen Engine-Presets zur Verfügung, die das Spritesheet direkt für Unity, Godot oder SpriteKit vorbereiten.

Was ist Onion Skin?

Onion Skin zeigt den vorherigen und/oder nächsten Frame halbtransparent an, während Sie den aktuellen Frame bearbeiten. So können Sie flüssige Animationen erstellen, da Sie die Bewegung zwischen den Frames sehen.

Funktioniert PlanktonSprite offline?

Ja. PlanktonSprite benötigt keine Internetverbindung. Alle Funktionen — Zeichnen, Animieren, Vorschau und Export — sind vollständig offline verfügbar.

Kann ich vorhandene Bilder importieren?

Ja. Sie können bestehende Bilder als Frames importieren und in PlanktonSprite weiterbearbeiten.

Werden meine Daten gespeichert oder geteilt?

Nein. PlanktonSprite erhebt keine Daten und benötigt keine Berechtigungen. Alle Projekte werden ausschließlich lokal auf Ihrem Gerät gespeichert. Weitere Informationen finden Sie in unserer Datenschutzerklärung.

PlanktonSprite (English)

About the App

PlanktonSprite is a pixel sprite animator for indie game developers. Create frame animations with onion skinning, export as GIF or spritesheet, and use engine presets for Unity, Godot, and SpriteKit — completely offline, no account required.

Frequently Asked Questions (FAQ)

What export formats are available?

PlanktonSprite exports as animated GIF and as spritesheet (PNG). Additionally, engine presets are available that prepare the spritesheet directly for Unity, Godot, or SpriteKit.

What is Onion Skin?

Onion Skin displays the previous and/or next frame semi-transparently while you edit the current frame. This allows you to create smooth animations by seeing the movement between frames.

Does PlanktonSprite work offline?

Yes. PlanktonSprite does not require an internet connection. All features — drawing, animating, preview, and export — are fully available offline.

Can I import existing images?

Yes. You can import existing images as frames and continue editing them in PlanktonSprite.

Is my data stored or shared?

No. PlanktonSprite does not collect any data and requires no permissions. All projects are stored locally on your device only. For more information, see our Privacy Policy.
