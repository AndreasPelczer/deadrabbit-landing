VoxelSprite

Über die App

VoxelSprite ist ein Minecraft Textur- und Resourcepack-Editor für iPad und Mac. Mit 7 spezialisierten Editoren (Block, Item, Skin, Painting, Entity, Armor, Crafting Recipe) erstellen Sie individuelle Texturpakete. Inklusive 3D-Vorschau, Pixel-Zeichenwerkzeugen und ZIP-Export — komplett offline, ohne Account.

Häufige Fragen (FAQ)

Wie exportiere ich mein Resourcepack?

Tippen Sie auf das Export-Symbol in der Toolbar. VoxelSprite erstellt automatisch eine ZIP-Datei im korrekten Minecraft-Format, die Sie direkt in Minecraft importieren können.

Funktioniert VoxelSprite offline?

Ja. VoxelSprite benötigt keine Internetverbindung. Alle Funktionen — einschließlich aller Editoren, der 3D-Vorschau und des Exports — sind vollständig offline verfügbar.

Welche Minecraft-Versionen werden unterstützt?

VoxelSprite erstellt Resourcepacks, die mit aktuellen Minecraft-Versionen (Bedrock und Java Edition) kompatibel sind. Das exportierte ZIP-Format folgt dem offiziellen Minecraft-Resourcepack-Standard.

Kann ich vorhandene Texturen importieren?

Ja. Sie können vorhandene Bilder als Ausgangspunkt für Ihre Texturen importieren und in den Pixel-Editoren weiterbearbeiten.

Werden meine Daten gespeichert oder geteilt?

Nein. VoxelSprite erhebt keine Daten und benötigt keine Berechtigungen. Alle Projekte werden ausschließlich lokal auf Ihrem Gerät gespeichert. Weitere Informationen finden Sie in unserer Datenschutzerklärung.

VoxelSprite (English)

About the App

VoxelSprite is a Minecraft texture and resource pack editor for iPad and Mac. With 7 specialized editors (Block, Item, Skin, Painting, Entity, Armor, Crafting Recipe), you can create custom texture packs. Includes 3D preview, pixel drawing tools, and ZIP export — completely offline, no account required.

Frequently Asked Questions (FAQ)

How do I export my resource pack?

Tap the export icon in the toolbar. VoxelSprite automatically creates a ZIP file in the correct Minecraft format that you can import directly into Minecraft.

Does VoxelSprite work offline?

Yes. VoxelSprite does not require an internet connection. All features — including all editors, 3D preview, and export — are fully available offline.

Which Minecraft versions are supported?

VoxelSprite creates resource packs compatible with current Minecraft versions (Bedrock and Java Edition). The exported ZIP format follows the official Minecraft resource pack standard.

Can I import existing textures?

Yes. You can import existing images as a starting point for your textures and edit them further in the pixel editors.

Is my data stored or shared?

No. VoxelSprite does not collect any data and requires no permissions. All projects are stored locally on your device only. For more information, see our Privacy Policy.
