O que é o iMOPS?

Não é uma ferramenta de checklists. É um sistema de controle determinístico.

O que o iMOPS NÃO é

  • Não é uma ferramenta de gestão de tarefas
  • Não são checklists digitais
  • Sem gamificação
  • Não é um caderno de colorir de fluxos de trabalho

O que o iMOPS É

  • Sistema de trabalho determinístico
  • Software de controle industrial
  • Documentação aprovada por autoridades
  • Trilha de auditoria à prova de adulteração

Funcionalidades principais

Tudo o que uma cozinha profissional precisa para conformidade HACCP.

🌡️

Funções principais HACCP

CCP-01 (temperatura interna), CCP-02 (refrigeração), PRP (limpeza/desinfecção com princípio dos quatro olhos). Quatro formulários de emergência imprimíveis como fallback em PDF.

🔗

SHA-256 Audit-Trail

Encadeamento tipo blockchain de todos os registros. Event sourcing com journal somente de adição. Exportação PDF aprovada por autoridades com selos de integridade.

🤖

Integração de IA (ChefIQ)

Reconhecimento OCR para recebimento de mercadorias e documentos. Conexão com Gemini-API e funcionalidade de scanner automatizada.

📡

Offline-First

Totalmente funcional offline – todas as funções operam sem WiFi. Sincronização multidispositivo via resolução de conflitos last-write-wins.

🛡️

Recuperação de falhas

Recuperação completa através de reprodução do journal. Arquitetura de kernel em RAM com segurança de threads e operações de fila serializadas.

📊

Gestão de dados

Ciclos de limpeza automáticos (90/180/365 dias). Backup/restauração com checksums SHA-256. Exportação CSV, JSON e PDF.

Arquitetura

Um kernel central em memória. Uma única fonte de verdade.
