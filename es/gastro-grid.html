¿Qué es iMOPS?

No es una herramienta de listas de control. Es un sistema de control determinista.

Lo que iMOPS NO es

  • No es una herramienta de gestión de tareas
  • No son listas de control digitales
  • Sin gamificación
  • No es un cuaderno de colorear de flujos de trabajo

Lo que iMOPS SÍ es

  • Sistema de trabajo determinista
  • Software de control industrial
  • Documentación apta para autoridades
  • Registro de auditoría a prueba de manipulaciones

Funciones principales

Todo lo que una cocina profesional necesita para el cumplimiento HACCP.

🌡️

Funciones principales HACCP

CCP-01 (temperatura interna), CCP-02 (refrigeración), PRP (limpieza/desinfección con principio de cuatro ojos). Cuatro formularios de emergencia imprimibles como respaldo PDF.

🔗

SHA-256 Audit-Trail

Encadenamiento tipo blockchain de todas las entradas. Event sourcing con journal de solo adición. Exportación PDF apta para autoridades con sellos de integridad.

🤖

Integración de IA (ChefIQ)

Reconocimiento OCR para recepción de mercancías y documentos. Conexión con Gemini-API y funcionalidad de escáner automatizada.

📡

Offline-First

Completamente funcional sin conexión – todas las funciones operan sin WiFi. Sincronización multidispositivo mediante resolución de conflictos last-write-wins.

🛡️

Recuperación ante fallos

Recuperación completa mediante reproducción del journal. Arquitectura de kernel en RAM con seguridad de hilos y operaciones de cola serializadas.

📊

Gestión de datos

Ciclos de limpieza automáticos (90/180/365 días). Respaldo/restauración con sumas de verificación SHA-256. Exportación CSV, JSON y PDF.

Arquitectura

Un kernel central en memoria. Una única fuente de verdad.
