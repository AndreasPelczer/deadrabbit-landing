Core Features

Everything a professional kitchen needs for HACCP compliance.

🌡️

HACCP Core Functions

CCP-01 (core temperature), CCP-02 (cooling), PRP (cleaning/disinfection with four-eyes principle). Four printable emergency forms as PDF fallback.

🔗

SHA-256 Audit Trail

Blockchain-like chaining of all entries. Event sourcing with append-only journal. Authority-grade PDF export with integrity seals.

🤖

AI Integration (ChefIQ)

OCR recognition for incoming goods and documents. Gemini-API connection and automated scanner functionality.

📡

Offline-First

Fully offline-capable – every function works without WiFi. Multi-device sync via last-write-wins conflict resolution.

🛡️

Crash Recovery

Complete recovery through journal replay. Thread-safe RAM kernel architecture with serialized queue operations.

📊

Data Management

Automatic cleanup cycles (90/180/365 days). Backup/restore with SHA-256 checksums. CSV, JSON, and PDF export.

Architecture

A central in-memory kernel. A single source of truth.
